# 💻 Hands-On LLM Code Lab & Notebooks

Practical code implementations, Jupyter notebooks, and experimentation with **Large Language Models**, LangChain, LlamaIndex, and open-source models (Llama, Mistral, Gemma).

---

## 🛠️ Stack & Frameworks
- **Frameworks:** LangChain, LlamaIndex, Transformers (Hugging Face)
- **Vector DBs:** Chroma, FAISS, Qdrant
- **Execution:** Python 3.11+, PyTorch, Ollama, vLLM
